# D-13 requires that where a client is hand-written, CI diff the hand-written types against
# the current published schema and fail on drift. This file is the hand-written side of that
# diff. `sift-graph`'s own tests check that every target the adapter can construct matches a
# template here and that every field it selects is listed here; `mise run graph-schema` checks
# the other half against the live metadata — which needs the network, so it belongs to the
# per-integration tier of D-63 rather than the per-change one.
#
# Templates are relative to the version root, which is the form a batch element takes.
#
# Format: METHOD<space>PATH-TEMPLATE<space>#<space>evidence
#
# Evidence is what the live check looks for in the published metadata:
#   nav:TYPE.PROPERTY   a navigation property on an entity type (or on one it derives from)
#   action:TYPE.NAME    an action bound to the entity type
#   documented:NAME     published in the reference documentation but not declared in the
#                       metadata, so the live check reports it as unchecked rather than passed
#
# SELECT lines name the fields a `$select` asks for, per entity type.
#
# **Nothing may be added here that sends.** The published metadata binds `send`, `reply`,
# `replyAll`, `forward` and their `create*` forms to the message type; none appears below, and
# the test beside this file fails if any ever does.
