# NFR-40 method 5: every published mutation-XSS payload, as a permanent regression vector.
#
# Format. A record is a header line, then exactly one payload line, taken byte for byte:
#
#   @ <id> | <expect> | <source>
#   <payload>
#
# <id> is `mx-NNN`, assigned in order and never renumbered, reused or removed. A vector that
# stops being interesting stays; that is what "permanent" means.
# <expect> is `clean` (the sanitizer accepts it and nothing forbidden survives into the
# re-parsed tree) or `rejected` (a bound in the limits register refuses it, and the message
# falls back to the raw view).
# <source> names the publication the shape comes from, the specification rule it exploits,
# or the earlier vector it is a variant of. A published payload is recorded in its canonical
# form, with the proof-of-concept call normalized to `alert(1)`; a variant says so.
# Lines starting with `#`, and blank lines, are ignored between records.
